# 何青泽：退化不变特征学习策略研究与验证计划

> 版本：2026-05-20  
> 目标：在尽量不重新训练 ColPali/ColQwen2 主干模型的前提下，研究并验证“退化文档图像”和“干净文档图像”在检索表示上的一致性增强方法。

## 1. 我对当前项目的理解

本项目是在官方 `colpali_engine` 的基础上叠加鲁棒性研究层。官方部分负责视觉文档检索，新增的 `robust/` 与 `experiments/` 负责退化、复原、评估和参数寻优。

当前主流程在 [experiments/run_benchmark.py](../../experiments/run_benchmark.py) 中：

```text
ViDoRe 数据集
  -> 读取 query 和 image
  -> process_queries(query) 编码查询
  -> 在 process_images(image) 之前插入预处理
  -> ColQwen2 编码文档图像
  -> score_multi_vector(query_vectors, document_vectors)
  -> nDCG@5 / Recall@5 / MRR
```

这意味着我们可以不动模型训练代码，直接在以下三个层次做鲁棒性增强：

1. 图像输入层：在 `processor.process_images(preprocessed)` 之前构造更稳的输入图像。
2. 文档嵌入层：在 `model(**inputs)` 输出多向量后，对文档 Patch 向量做过滤、加权、融合或校准。
3. MaxSim 打分层：在 `processor.score_multi_vector(...)` 或其替代函数中改变“哪些 Patch 贡献得分、贡献多少”。

你的任务是“退化不变特征学习策略”，严格来说属于第 2 和第 3 层，而不是分割或图像复原本身。我们可以把前端退化/复原同学的结果作为输入，但你这边的核心问题应表述为：

> 对同一个页面，退化图像得到的多向量表示 `E_d^deg`，能否在不重训或极少校准的情况下更接近干净图像表示 `E_d^clean`，并让最终检索排序更接近 clean baseline？

## 2. ColPali / ColQwen2 论文与代码要点

ColPali 论文《ColPali: Efficient Document Retrieval with Vision Language Models》提出直接把文档页面图像作为检索对象，不走 OCR、版面解析、分块、文本嵌入这一长链路。论文版本信息可见 arXiv：该论文 2024-06-27 提交，2025-02-28 修订为 v6，并作为 ICLR 2025 conference paper 发表。论文摘要强调：ColPali 训练 VLM 从文档页面图像生成高质量多向量嵌入，并结合 late interaction 显著优于传统文档检索流水线。来源：[arXiv:2407.01449](https://arxiv.org/abs/2407.01449)。

Hugging Face 官方博客也把核心思想讲得很直观：索引阶段直接使用页面截图，PaliGemma/Qwen2-VL 这类 VLM 把图像切成 Patch，经语言模型上下文化后投影到低维空间；查询阶段把文本查询编码成 token 向量；最终用 ColBERT 风格的 late interaction，让每个查询 token 去找最相似的文档 Patch。来源：[Hugging Face ColPali blog](https://huggingface.co/blog/manu/colpali)。

对应到本仓库代码：

- [colpali_engine/models/qwen2/colqwen2/modeling_colqwen2.py](../../colpali_engine/models/qwen2/colqwen2/modeling_colqwen2.py) 中 `ColQwen2.forward()` 输出形状约为 `(batch, sequence_length, 128)` 的 L2 归一化多向量。
- [colpali_engine/models/qwen2/colqwen2/processing_colqwen2.py](../../colpali_engine/models/qwen2/colqwen2/processing_colqwen2.py) 中 `process_images()` 把 PIL 图像转成 Qwen2-VL 所需输入，并保留 `image_grid_thw`，这对后续 Patch 位置映射很重要。
- [colpali_engine/utils/processing_utils.py](../../colpali_engine/utils/processing_utils.py) 中 `score_multi_vector()` 是核心 MaxSim：

```python
scores = torch.einsum("bnd,csd->bcns", qs_batch, ps_batch).max(dim=3)[0].sum(dim=2)
```

这行代码含义是：对每个 query token，找所有 document token/Patch 里相似度最高的那个，再把所有 query token 的最大相似度求和。

这个机制性能强，但也带来退化鲁棒性问题：如果某些退化 Patch 因噪声、模糊、压缩伪影产生了异常高相似度，它会被 `max(dim=3)` 选中，直接影响最终分数。你的工作可以自然落在“让退化 Patch 不乱抢 MaxSim”的方向上。

## 4. 你的研究问题应如何重新聚焦

开题报告中对何青泽的分工写的是：

1. 基于对比学习的退化不变性增强。
2. 风格归一化或域对抗训练。
3. 在合成退化数据集上验证检索鲁棒性。

这些表述偏“训练型”。但你现在希望尽量不重训，所以建议改成一个更工程可落地、也更符合当前代码状态的研究问题：

> 在冻结 ColQwen2 模型参数的条件下，通过多视图嵌入融合、Patch 置信度加权、嵌入空间校准和鲁棒 MaxSim 打分，提升退化文档检索的 nDCG@5，并分析这些方法对干净图、退化图和复原图嵌入一致性的影响。

这样写的好处是：即使没有退化数据集，你也能先基于 `robust/degradation` 合成退化版本；即使不训练模型，也能做足够完整的实验、可解释分析和消融。

## 5. 推荐方案总览：尽量不重训的优先级

我建议按“完全不训练 -> 少量校准 -> 轻量训练兜底”的顺序推进。

| 优先级 | 方法 | 是否训练 | 改动位置 | 预期收益 | 风险 |
| --- | --- | --- | --- | --- | --- |
| P0 | 多视图嵌入融合 | 不训练 | 文档编码后 / 打分前 | 稳，容易出结果 | 推理成本增加 |
| P0 | 退化感知 Patch 加权 MaxSim | 不训练 | `score_multi_vector` 替代函数 | 与你的分工最贴合 | 质量权重设计需调参 |
| P1 | Patch 过滤与鲁棒 Top-k MaxSim | 不训练 | 打分层 | 抑制噪声 Patch 抢最大值 | 过滤过强会漏掉有效文字 |
| P1 | 嵌入空间归一化/去偏 | 不训练或只校准 | 文档向量后处理 | 简单，适合做消融 | 可能损伤正常语义 |
| P2 | 干净-退化配对校准 | 不训主干，只拟合统计量 | 嵌入后处理 | 更像“退化不变特征学习” | 需要少量 clean-degraded 对 |
| P3 | 冻结主干的小门控/线性层 | 轻量训练 | 新增小模块 | 效果上限更高 | 与“不训练”目标有冲突 |

下面展开每一种方法。

## 6. 方法一：多视图嵌入融合

### 6.1 核心思想

对同一张退化文档图像，不只编码一个版本，而是编码多个视图：

```text
原始退化图 y
轻度去噪图 denoise(y)
锐化图 sharpen(y)
轻度平滑图 gaussian(y)
去倾斜图 deskew(y)
```

然后在检索时把这些视图的得分融合，而不是试图判断哪一个一定最好。

最简单的融合：

```text
score(q, d) = max(
  score(q, d_original),
  score(q, d_denoised),
  score(q, d_sharpened)
)
```

更稳一点的融合：

```text
score(q, d) = 0.5 * score_original + 0.3 * score_denoised + 0.2 * score_sharpened
```

或者使用 Reciprocal Rank Fusion：

```text
RRF(d) = sum_v 1 / (k + rank_v(d))
```

### 6.2 为什么适合你

这不是“复原模块”的重复工作，因为你的重点不是提出新复原算法，而是验证：

> 退化不变性是否可以通过多视图表示的互补性获得，而不必改模型权重？

ColPali/ColQwen2 的 MaxSim 本来就允许一个查询 token 匹配不同 Patch。多视图融合进一步允许它在不同图像处理版本中选择更可靠的 Patch。

### 6.3 结合当前代码怎么接

当前 [experiments/run_benchmark.py](../../experiments/run_benchmark.py) 中：

```python
preprocessed = preprocess_fn(images[i:i+BATCH_SIZE])
inputs = processor.process_images(preprocessed).to(DEVICE)
with torch.no_grad():
    vecs = model(**inputs)
all_d_vecs.extend([v.cpu().float() for v in vecs])
```

未来实现时可以把这里扩展为：

```text
对每个 batch:
  views = [
    original_images,
    denoised_images,
    sharpened_images,
  ]
  每个 view 单独 process_images + model
  保存为 all_d_vecs_by_view

打分时:
  对每个 view 算 scores_matrix
  对多个 scores_matrix 做 max/weighted/RRF 融合
```

本阶段不需要写代码，但实验计划中应把它作为第一个主方案，因为成功率最高、解释简单、和“不训练”完全一致。

### 6.4 实验设计

建议先做这几组：

| 实验名 | 输入 | 融合方式 |
| --- | --- | --- |
| degraded_only | 退化图 | 无 |
| degraded_nlmeans | 退化图 + NLMeans 图 | max score |
| degraded_gaussian | 退化图 + Gaussian 图 | max score |
| degraded_all_views | 退化图 + NLMeans + Gaussian + Wiener | max score / weighted score |

评价看三件事：

1. nDCG@5 是否比 `degraded_only` 高。
2. 是否接近 `clean`。
3. 推理耗时增加几倍，是否还能接受。

## 7. 方法二：退化感知 Patch 加权 MaxSim

### 7.1 核心思想

原始 MaxSim 是：

```text
score(q, d) = sum_i max_j <q_i, d_j>
```

退化感知加权改成：

```text
score(q, d) = sum_i max_j w_j * <q_i, d_j>
```

其中 `w_j` 是第 `j` 个文档 Patch 的质量置信度，范围建议为 `[0, 1]`。质量高的文字/图表 Patch 权重大，背景、噪声、压缩伪影、模糊严重的 Patch 权重小。

这非常贴合开题报告中“退化严重的 Patch 可能产生误导性的高相似度响应，动态降低低质量 Patch 贡献”的描述，而且完全可以不训练模型。

### 7.2 Patch 权重怎么来

不训练版本可以先用图像统计特征：

| 权重信号 | 直觉 | 可能实现 |
| --- | --- | --- |
| 局部梯度强度 | 文本文字边缘通常清晰，纯背景梯度低 | Sobel / Laplacian |
| 局部方差 | 空白背景和强平滑区域信息量低 | patch variance |
| 模糊程度 | 模糊 Patch 细节少 | Laplacian variance |
| 饱和/噪声比例 | 强噪声、椒盐点可能是伪影 | 极端像素比例 |
| OCR-like textness | 文档文字区域有稳定笔画结构 | 边缘密度 + 连通域 |

一个可解释的手工权重可以写成：

```text
w_j = sigmoid(
  a * edge_density_j
  + b * local_contrast_j
  - c * noise_score_j
  - d * blur_score_j
)
```

如果担心手工公式太复杂，可以先从最稳的二值过滤开始：

```text
低信息 Patch: local_variance < threshold
处理方式: w_j = 0.3
其他 Patch: w_j = 1.0
```

### 7.3 怎么映射图像 Patch 到嵌入 Patch

ColQwen2 处理图像时会产生 `image_grid_thw`，当前 [processing_colqwen2.py](../../colpali_engine/models/qwen2/colqwen2/processing_colqwen2.py) 中也有：

```python
offsets = batch_doc["image_grid_thw"][:, 1] * batch_doc["image_grid_thw"][:, 2]
```

这说明每张图的视觉 token 数可由 `height_grid * width_grid` 得到。未来做 Patch 权重时，可以用同样的网格数量把原图 resize/划分成对应块，然后为每个视觉 Patch 生成 `w_j`。

需要注意：`ColQwen2.forward()` 默认 `mask_non_image_embeddings=False`，返回序列里可能包含 prompt 文本 token 和 image token。要精确加权，建议未来实验中优先使用 `processor.get_image_mask(batch_images)` 或 `input_ids == image_token_id` 找出图像 token，只对图像 token 加权，非图像 token 保持 1 或单独屏蔽。

### 7.4 结合当前 MaxSim 代码怎么讲

原始打分在 [processing_utils.py](../../colpali_engine/utils/processing_utils.py)：

```python
torch.einsum("bnd,csd->bcns", qs_batch, ps_batch).max(dim=3)[0].sum(dim=2)
```

加权版概念上是：

```text
sim = einsum(q, p)              # b, c, n_query, n_doc
sim_weighted = sim * weights    # weights: c, n_doc
score = sim_weighted.max(doc_dim).sum(query_dim)
```

这不是训练，只是改变打分策略。报告里可以强调：ColPali 的多向量 late interaction 给了我们“Patch 级干预点”，这正是传统单向量检索没有的优势。

### 7.5 实验设计

建议做以下消融：

| 实验名 | 权重策略 | 目的 |
| --- | --- | --- |
| maxsim_baseline | 原始 MaxSim | degraded baseline |
| variance_weighted | 局部方差权重 | 去掉空白/低信息 Patch |
| edge_weighted | 边缘密度权重 | 保留文字/表格线区域 |
| blur_penalty | 模糊惩罚 | 降低运动模糊 Patch |
| combined_quality | 综合质量分 | 主结果 |

核心指标除了 nDCG@5，还建议加：

```text
被降权 Patch 比例
平均权重
Top-1 MaxSim 命中的低质量 Patch 比例
```

这些指标可以证明方法确实在“减少低质量 Patch 干扰”，不是只报一个分数。

## 8. 方法三：鲁棒 Top-k MaxSim

### 8.1 核心思想

原始 MaxSim 对每个 query token 只取最大值：

```text
max_j sim(i, j)
```

这在有噪声时比较脆弱，因为一个异常 Patch 就可能抢走最大值。可以改为 Top-k 稳健聚合：

```text
topk_mean_i = mean(top_k(sim(i, :), k=3))
score = sum_i topk_mean_i
```

或者更保守：

```text
score = sum_i median(top_k(sim(i, :), k=5))
```

### 8.2 为什么不需要训练

这只是把 `max` 换成更稳的聚合函数，不更新模型参数。它可以作为 Patch 加权的对照组：

- 如果 Top-k 有效，说明退化主要问题是异常最大值。
- 如果 Patch 加权更有效，说明质量先验确实有帮助。

### 8.3 适合写进报告的公式

```text
LI_topk(q, d) = sum_i mean(TopK_j(<q_i, d_j>, k))
```

若结合权重：

```text
LI_weighted_topk(q, d) = sum_i mean(TopK_j(w_j * <q_i, d_j>, k))
```

## 9. 方法四：嵌入空间归一化与去偏

### 9.1 核心思想

退化可能在文档嵌入里引入某种“全局风格偏移”，例如噪声让很多 Patch 向某些方向漂移。我们可以在不训练模型的情况下，对每页的多向量做后处理：

```text
E = document patch embeddings
E_centered = E - mean(E)
E_normed = normalize(E_centered)
```

也可以做更温和的去偏：

```text
E' = normalize(E - alpha * page_mean)
```

其中 `alpha` 是超参数，可从 `{0.0, 0.25, 0.5, 0.75}` 网格搜索。

### 9.2 为什么可能有效

ColQwen2 输出已经做了 L2 normalize，但这是每个 token 自身的归一化，不保证同一页面内的整体风格偏移被消除。对页面级均值做去偏，有点像把“共同背景风格”减掉，让 Patch 间的相对语义更突出。

### 9.3 风险

这类方法可能伤害干净图性能，因为页面全局均值也可能包含真实语义信息。所以它更适合作为 P1 消融，不建议一开始当主方案。

## 10. 方法五：干净-退化配对的嵌入校准

### 10.1 核心思想

如果后续已经有合成退化数据，那么每个页面都有 `(clean_image, degraded_image)` 配对。即使不训练 ColQwen2，也可以在嵌入空间估计退化方向：

```text
delta_k = mean(E_degraded_k) - mean(E_clean)
```

对某类退化 `k`，估计平均偏移：

```text
Delta_k = average_pages(delta_k)
```

推理时校正：

```text
E_degraded_corrected = normalize(E_degraded - beta * Delta_k)
```

这里的 `Delta_k` 是统计量，不是神经网络参数。严格说这属于“无监督/弱监督校准”，不属于重训模型。

### 10.2 更贴近“退化不变特征学习”的表达

这个方法可以在报告中命名为：

> Frozen Encoder Degradation Direction Removal

中文可写：

> 冻结编码器下的退化方向消除。

它的理论目标是让：

```text
distance(E_clean, E_degraded_corrected)
<
distance(E_clean, E_degraded)
```

同时让：

```text
nDCG(E_degraded_corrected)
>
nDCG(E_degraded)
```

### 10.3 验证指标

除了检索指标，建议加嵌入一致性指标：

```text
PageMeanCos = cos(mean(E_clean), mean(E_degraded))
PatchChamfer = symmetric nearest-neighbor distance between patch sets
ScoreGap = LI(q_i, d_i_clean) - LI(q_i, d_i_degraded)
RankGap = rank_degraded(i) - rank_clean(i)
```

这些指标可以支撑“特征不变性”这一主题，而不仅仅是报检索分数。

## 11. 方法六：冻结主干的小型门控模块，作为最后兜底

如果课程后期发现完全不训练的方法提升有限，可以考虑一个非常轻量的方案，但要在报告中明确它不是重训 ColQwen2 主干：

```text
冻结 ColQwen2
冻结 custom_text_proj
只训练一个 Patch quality gate 或 128 维线性校准层
训练数据来自 clean-degraded 合成对
损失只约束 E_clean 与 E_degraded 的一致性
```

可选损失：

```text
L_align = 1 - cos(mean(E_clean), mean(E_degraded_corrected))
L_rank = max(0, margin - score(q, d_pos) + score(q, d_neg))
L_reg = ||gate - 1||，避免过度修改
```

但这个方案放在 P3，不建议现在优先做。你的主线应尽量保持“不训练”。

## 12. 推荐实验矩阵

等退化数据准备好后，你可以按下面顺序跑。这样即使时间紧，也能逐步交付。

### 第 1 阶段：建立退化敏感性基线

| 条件 | 目的 |
| --- | --- |
| clean | 上限基线 |
| degraded_light_noise | 轻噪声损伤 |
| degraded_heavy_noise | 重噪声损伤 |
| degraded_motion_blur | 模糊损伤 |
| degraded_jpeg_low | 压缩损伤 |
| degraded_tilt | 几何损伤 |
| degraded_combined | 组合损伤 |

输出：

```text
nDCG_clean
nDCG_degraded
退化损失曲线
```

### 第 2 阶段：完全不训练的方法

| 方法 | 对照对象 |
| --- | --- |
| 多视图 max 融合 | degraded_only |
| 多视图 weighted 融合 | degraded_only |
| Patch variance weighting | 原始 MaxSim |
| Patch edge weighting | 原始 MaxSim |
| Top-k MaxSim | 原始 MaxSim |
| Weighted Top-k MaxSim | Patch weighting 与 Top-k 单独版本 |

输出：

```text
鲁棒增益
恢复率
耗时增加
不同退化类型下的适用性
```

### 第 3 阶段：嵌入一致性分析

| 分析 | 说明 |
| --- | --- |
| clean vs degraded PageMeanCos | 衡量整页嵌入偏移 |
| clean vs method PageMeanCos | 看方法是否拉近表示 |
| score gap | 正确文档得分是否恢复 |
| top patch 可视化 | 看退化 Patch 是否被降权 |

这部分是你报告里最“研究味”的内容。只做 nDCG 会像工程调参；加入嵌入一致性和 Patch 贡献分析，才更像“退化不变特征学习策略”。

## 14. 报告中可以这样表述你的贡献

建议写成三点：

1. 构建了冻结 ColQwen2 条件下的退化不变特征验证框架，将鲁棒性问题从图像质量提升转化为多向量嵌入一致性与检索排序恢复问题。
2. 提出了无需重训的退化感知 Patch 加权 MaxSim 方法，利用图像局部质量先验抑制低质量 Patch 在 late interaction 中产生误导性最大响应。
3. 设计了多视图嵌入融合与鲁棒 Top-k MaxSim 作为无训练增强策略，并通过 nDCG@5、恢复率、嵌入相似度和 Patch 贡献分析验证其有效性。

如果后续效果一般，也可以诚实写：

> 实验表明，单纯图像复原或手工 Patch 权重并不总能稳定提升检索性能，说明 ColQwen2 的退化鲁棒性主要受语义对齐空间影响，而非视觉质量单因素决定。这为后续引入轻量校准层或对比式适配提供了依据。

这个结论也成立，而且很像一个可靠的课程研究结果。

## 15. 我最推荐你优先做的方案

如果只能选择一条主线，我建议：

```text
主方案：退化感知 Patch 加权 MaxSim
辅助方案：多视图 score 融合
分析工具：clean-degraded 嵌入一致性指标
```

原因：

1. 不需要重训，符合当前约束。
2. 直接作用在 ColPali 最核心的 late interaction 机制上，而不是泛泛做图像增强。
3. 和开题报告中的“退化严重 Patch 产生误导性高相似度响应”完全对应。
4. 易于做可解释图：可以展示哪些 Patch 被降权，哪些 query token 的匹配变得更合理。
5. 即使最终提升不大，也能得到清晰结论：哪些退化类型主要影响 Patch 质量，哪些退化类型需要真正的表示学习或轻量校准。
