
以本次重跑的 `clean singleview` 和 `degraded singleview` 为基准：

| 指标 | 退化损失 |
| --- | ---: |
| nDCG@5 | 0.1081254731561258 |
| Recall@5 | 0.1571223316912973 |
| MRR | 0.03496518844170404 |

### 7.1 multiview baseline

| 指标 | 相对 degraded 增益 | 恢复率 |
| --- | ---: | ---: |
| nDCG@5 | +0.005090035892024836 | 4.71% |
| Recall@5 | -0.0012999452654625099 | -0.83% |
| MRR | +0.015021555342478399 | 42.96% |

解释：

```text

但 Recall@5 没有改善。

```

### 7.2 invariant calibration

| 指标 | 相对 degraded 增益 | 恢复率 |
| --- | ---: | ---: |
| nDCG@5 | -0.017337694974040252 | -16.03% |
| Recall@5 | -0.01629720853858796 | -10.37% |
| MRR | -0.01213913791595167 | -34.72% |

解释：

```text
第一版 token-wise linear calibration 没有提升检索，
反而让三个检索指标都低于 degraded singleview。
```

这不是代码没有跑通，而是一个负结果：

```text
仅用 page-level InfoNCE + cosine alignment 训练一个线性映射，
虽然能降低训练 loss，
但会破坏 ColQwen2 原始 late interaction / MaxSim 所依赖的 token-level 结构。
```

## 8. 本次结论

本次实际运行可以明确得到四个结论。

第一，默认 multiview 开关改造成功。

```text
run_local_hr_benchmark.py 默认 use_multiview=false，
只有显式传入 --use-multiview 才会进入多视图路径。
```

第二，退化确实造成表示漂移。

```text
clean/degraded 同页 mean-pooled embedding 平均 cosine 约为 0.533，
score matrix Pearson 约为 0.762，
说明退化已经改变了文档表示和检索排序结构。
```

第三，multiview 只能作为 baseline。

```text
weighted multiview 对 MRR 有明显恢复，
对 nDCG@5 只有小幅恢复，
对 Recall@5 没有收益。
考虑推理成本后，它不适合作为主线方法。
```

第四，第一版 invariant calibration 是负结果。

```text
线性校准层训练目标下降明显，
但检索指标下降。
这说明“拉近页面级 embedding”不足以保证 MaxSim 检索变好，
后续需要更精细地保护 token-level late interaction 结构。
```

## 9. 后续建议

后续不要直接把当前 calibration 写成成功方法，而应写成第一版验证：

```text
退化表示漂移存在；
简单线性校准不足以修复检索；
需要设计更符合 ColQwen2 多向量 late interaction 的退化不变学习目标。
```

建议下一步围绕何青泽方向继续做三件事：

1. 从 `query_drop_cases.csv` 中挑选 degraded 后 rank 明显变差的 query，做 case study。
2. 将 calibration loss 从 page-level mean pooling 改为 token-level matching 或 score-level distillation。
3. 用 clean score matrix 作为 teacher，让 degraded/calibrated score matrix 靠近 clean，而不是只让页面 embedding 均值靠近。

更合适的下一版目标可以写成：

```text
冻结 ColQwen2 主干，
使用 clean 页面检索分数或 token-level MaxSim 响应作为监督，
学习一个不破坏 late interaction 排序结构的退化不变校准模块。
```
