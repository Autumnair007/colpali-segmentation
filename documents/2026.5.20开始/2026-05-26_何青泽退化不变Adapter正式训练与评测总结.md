# 2026-05-26 何青泽退化不变 Adapter 正式训练与评测总结

## 结论

本报告是 2026-05-25 到 2026-05-26 两天工作的完整整理，覆盖本地 111 页退化子集接入、退化敏感性验证、表示漂移分析、失败方法复盘、标准推理对齐、稳健 Late Interaction 试验，以及最终冻结 ColQwen2 的退化不变 Adapter 训练结果。

本轮已经得到一个可用结果：`tune_distill6` 配置在主 raw degraded 测试集 `PD_MB_GN_JC_LR_CS` 上明显优于原始 ColQwen2 MaxSim。

- 主测试 `nDCG@5`: `0.4506 -> 0.4997`，提升 `+0.0491`。
- 主测试 `Recall@5`: `0.3727 -> 0.4259`，提升 `+0.0532`。
- 主测试 `MRR`: `0.5957 -> 0.6372`，提升 `+0.0414`。
- 该提升超过原先设定的 `nDCG@5 +0.01` 合格线，也超过 `+0.03` 理想线。因此本轮不继续调参，转入整理记录。

补充的 proxy restored 测试中，`gaussian / nlmeans / wiener` 三个 proxy 的 `nDCG@5` 都有正提升；但 5 个额外高强度 raw held-out variant 的平均 `nDCG@5` 略降，说明当前 adapter 对主测试组合有效，对所有高强度组合的泛化仍不稳定。

最重要的科学结论有两点：

1. 退化确实造成了 ColQwen2 文档表示漂移。5 月 25 日的漂移分析显示，同一页面 clean 与 degraded 的 mean-pooled page embedding 平均 cosine 只有 `0.5327`，clean/degraded score matrix 的 Pearson/Spearman 也只有 `0.7622 / 0.7355`，说明退化不只是图像质量下降，也改变了表示空间和排序结构。
2. 最终有效的 Adapter 不是靠简单地把 page-level mean embedding 拉回 clean，而是靠 clean teacher score matrix 和 qrels 排序约束，修正 Late Interaction 层面的检索分数。补充漂移计算显示，Adapter 后主测试 page-level mean cosine 反而从 `0.5327` 降到 `0.3108`，但检索 `nDCG@5` 提升 `+0.0491`。这说明“均值向量更像 clean”不是充分目标，真正应该优化的是多向量 MaxSim 排序行为。

```text
冻结 ColQwen2 主干
-> 缓存 clean/degraded/restored page embeddings
-> 分析退化造成的表示漂移和排序漂移
-> 用 clean score matrix 作为 teacher

```

## 两天工作脉络

### 2026-05-25：先证明问题存在，再淘汰弱方法

5 月 25 日主要做了四件事。

第一，接入本地 111 页退化子集。这个子集对应同一份主文档 `employment_and_social_developments_in_europe_2024-KEBD24002ENN`，同时有 clean 页图和多种 degraded 页图，因此适合做 clean/degraded 严格配对分析。

第二，复现 singleview baseline，确认退化真的会伤害检索。全量 174 query 口径下，clean singleview 到 degraded singleview 的下降约为：

| 指标 | clean singleview | degraded singleview | 退化损失 |
|---|---:|---:|---:|
| nDCG@5 | 0.5728 | 0.4647 | -0.1081 |
| Recall@5 | 0.5750 | 0.4179 | -0.1571 |
| MRR | 0.6636 | 0.6286 | -0.0350 |

第三，做表示漂移分析。结果显示 clean/degraded 同页 mean-pooled embedding 平均 cosine 只有 `0.5327`，并且有页面低到 `-0.0815`。这说明退化不是只降低像素质量，而是把文档页面推离了 clean 表示空间。

第四，尝试并淘汰两个弱方法：

| 方法 | 结果 | 判断 |
|---|---|---|
| weighted multiview | degraded nDCG@5 约 `+0.0051`，MRR 约 `+0.0150`，Recall@5 略降 | 有轻微帮助，但推理成本高，不作为主方法 |
| 第一版 invariant calibration | nDCG@5 `-0.0173`，Recall@5 `-0.0163`，MRR `-0.0121` | 负结果，说明 page-level 对齐目标会破坏 MaxSim 排序结构 |

### 2026-05-26：回到标准推理，再转向轻训练 Adapter

5 月 26 日先清理旧改进，回到标准 singleview MaxSim 作为统一 baseline。随后补了一组免训练稳健 Late Interaction：

| 方法 | nDCG@5 gain | Recall@5 gain | MRR gain | 判断 |
|---|---:|---:|---:|---|
| Top-k mean, k=2 | +0.0022 | -0.0015 | +0.0105 | 弱正 |
| Top-k mean, k=3 | +0.0055 | +0.0042 | +0.0138 | 三项正但幅度小 |
| SmoothMax, tau=0.05 | -0.0083 | -0.0099 | -0.0076 | 负结果 |

这些免训练方法说明“只改 MaxSim 聚合”有一点空间，但提升不足以支撑一个强结论。因此最终切换到轻训练方案：冻结 ColQwen2，只训练一个 128 维 residual adapter，在 embedding 层对 degraded/restored 表示做小幅变换，并直接以 clean 检索分数矩阵和 qrels 排序为监督。

## 表示漂移分析

漂移分析是这两天工作的关键证据链：先证明退化确实改变了 ColQwen2 表示，再解释为什么第一版 calibration 失败，最后说明为什么 score distillation adapter 能成功。

### 5 月 25 日：退化导致 clean/degraded 表示空间偏移

漂移分析来自：

```text
results/invariant_features/feature_drift_summary.json
results/invariant_features/page_level_similarity.csv
results/invariant_features/query_drop_cases.csv
```

主退化 variant 为 `PD_MB_GN_JC_LR_CS`，page count 为 111。

| 漂移指标 | 数值 |
|---|---:|
| mean page cosine | 0.532664843331519 |
| min page cosine | -0.08147381991147995 |
| mean page L2 | 0.8958806430434322 |
| max page L2 | 1.4706963300704956 |
| score matrix Pearson | 0.762178361415863 |
| score matrix Spearman | 0.7354867458343506 |

直观解释：

```text
如果退化只影响人眼观感，而不影响模型语义表示，
同一页 clean/degraded embedding 的 cosine 应该很接近 1。
现在平均只有 0.533，说明模型看到的“同一页”已经明显变成了另一个方向的表示。
```

score matrix correlation 仍有 `0.76 / 0.74`，说明模型并非完全失效；它还保留了一部分语义检索能力。但相关性没有高到接近 1，说明 query-page 排序结构已经被明显扰动。这也解释了为什么 degraded singleview 的 `nDCG@5 / Recall@5` 比 clean 低很多。

query rank change 进一步说明退化影响不是均匀的：

| 类型 | query 数 |
|---|---:|
| degraded 后首个 relevant rank 变差 | 55 |
| degraded 后首个 relevant rank 变好 | 49 |
| 不变 | 70 |

这里的重点不是“有些 query 变好”，而是退化会重新排列 query-page 的相对分数。对部分 query，噪声、模糊或压缩伪影可能削弱了真正相关页；对另一些 query，退化偶然改变了非相关页的相似度。这就是后续必须做 per-query rank delta 的原因。

### 为什么第一版 calibration 失败

5 月 25 日的线性 calibration 用 page-level InfoNCE + cosine alignment 训练，loss 确实下降，但检索指标下降：

| 方法 | nDCG@5 | Recall@5 | MRR |
|---|---:|---:|---:|
| degraded singleview | 0.4647 | 0.4179 | 0.6286 |
| degraded invariant calibration | 0.4473 | 0.4016 | 0.6165 |
| gain | -0.0173 | -0.0163 | -0.0121 |

这说明一个很重要的负结果：

```text
把页面均值 embedding 拉近 clean，不等价于让 ColQwen2 的 MaxSim 检索变好。
```

ColQwen2 的核心不是单个页面向量，而是 query token 和 document token/Patch 之间的 late interaction：

```text
score(q, d) = sum_i max_j <q_i, d_j>
```

如果校准层破坏了 token-level 局部匹配结构，即使 page-level 均值更接近 clean，最终排名也可能变差。因此 5 月 26 日的方法改成直接蒸馏 clean score matrix，并用 qrels 约束排序。

### 5 月 26 日：Adapter 后的漂移现象

为了补充 Adapter 的表示解释，我额外计算了 adapter 前后 page-level mean embedding 与 clean 的 cosine / L2。结果保存于：

```text
artifacts/invariant_adapter/tune_distill6_seed13/adapter_embedding_drift_summary.json
```

主测试 `PD_MB_GN_JC_LR_CS`:

| 指标 | adapter 前 | adapter 后 | 变化 |
|---|---:|---:|---:|
| mean page cosine vs clean | 0.5327 | 0.3108 | -0.2219 |
| min page cosine vs clean | -0.0815 | -0.1171 | -0.0357 |
| mean page L2 vs clean | 0.8959 | 1.1609 | +0.2650 |
| cosine 改善页数 | - | 13 / 111 | - |
| cosine 变差页数 | - | 98 / 111 | - |

三个 proxy restored 也有类似现象：

| 输入 | mean cosine 前 | mean cosine 后 | nDCG@5 gain |
|---|---:|---:|---:|
| gaussian proxy | 0.5568 | 0.3257 | +0.0164 |
| nlmeans proxy | 0.5603 | 0.3440 | +0.0141 |
| wiener proxy | 0.5630 | 0.3395 | +0.0183 |

这个结果乍看反直觉：为什么更不像 clean，检索反而更好？

答案是本轮 Adapter 不是在优化 page-level mean cosine，而是在优化：

1. degraded/restored score distribution 接近 clean teacher score distribution；
2. qrels positive pages 在当前 query 下排得更靠前；
3. adapter 不要过度破坏原始 token embedding。

也就是说，Adapter 学到的不是“全局均值回到 clean 方向”，而是“在 query-token 与 document-token 的 MaxSim 结构里，让相关页的分数关系更接近 clean”。这正好回应了 5 月 25 日 calibration 的失败原因：退化不变特征学习不能只看单页均值，要看检索分数矩阵和排序。

### 漂移分析对泛化结果的解释

额外 high-strength raw held-out variant 中，`PD_GN_JC_LR_CS` 原始 mean cosine 已经非常高：

| variant | mean cosine 前 | mean cosine 后 | nDCG@5 gain |
|---|---:|---:|---:|
| `PD_GN_JC_LR_CS` | 0.9108 | 0.4713 | -0.0426 |

这说明某些未训练退化组合本身已经离 clean 很近，强行套用只在 6 个单退化上训练出的 adapter，反而会把表示推离原来的良好区域，导致排序变差。这解释了为什么额外 5 个 raw held-out variant 的平均 nDCG@5 是负的，也提示下一轮必须把训练 variant 扩展到更复杂的组合，而不是继续只用单退化训练。

## 方法

ColQwen2 主干全程冻结，只训练 embedding 层 residual adapter。

Adapter:

```text
LayerNorm(128) -> Linear(128, 256) -> GELU -> Linear(256, 128)
output = normalize(x + clamp(scale, 0, 0.5) * adapter(x))
```

Loss:

```text
L = score_weight * L_score_distill
  + rank_weight * L_qrels_rank
  + identity_weight * L_identity
```

本轮最佳配置为 `tune_distill6`:

```text
score_weight=2.0
rank_weight=0.5
identity_weight=0.01
temperature=0.07
lr=1e-3
epochs=30
patience=6
best_epoch=2
```

## 后续建议

短期可以把 `tune_distill6` 作为当前阶段的正式方法结果写入研究记录，因为主测试提升已经足够明显。

如果后续要追求更强泛化，建议下一轮不要继续围绕当前 6 个单退化微调，而是改成 hard variant 训练，例如：

```text
--variant-order hard --max-variants 12
--variant-order hard --max-variants 18
--max-variants 30
```

核心目标是让训练分布覆盖更多三退化/双退化组合，而不是继续加 epoch。当前早停 best epoch 为 2，说明不是训练轮数不足，而是训练 variant 覆盖不足。
