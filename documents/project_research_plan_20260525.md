# ColPali-Robust 最新研究方案与分工

更新时间：2026-05-25

## 研究目标

本项目面向真实场景中的退化文档图像，研究 ColPali/ColQwen2 等视觉语言检索模型的鲁棒感知能力。核心目标是建立统一、可控的文档图像退化模型，并发展退化不变的特征学习与退化感知推理策略，使模型能够剥离由设备、环境和载体老化引入的外观干扰，稳定理解文档版面结构与语义内容。

## 研究内容一：退化图像合成与前端复原

真实文档图像常受到多种物理因素耦合影响，包括光照不均、运动模糊、透视畸变、墨迹洇染、低分辨率、JPEG 压缩和色彩偏移。这些退化因素会改变文档图像的视觉质量，也会干扰 ColPali 的 Patch 级嵌入和延迟交互得分。

本方向分为两个层次：

1. 数据层：构建参数化文档退化合成管线。以 ViDoRe 干净文档图像为原始素材，批量生成覆盖单一退化与多退化耦合的受损数据集。每类退化都需要记录类型、强度、随机种子和输出路径，保证实验可控、可解释、可复现。
2. 复原层：研究轻量级前端复原方法。针对噪声、模糊、压缩失真和几何倾斜分别集成传统图像处理与轻量深度复原模型，重点评估“视觉质量提升”是否必然带来检索性能提升。

推荐基准对比：

| 条件 | 说明 |
| --- | --- |
| clean | 原始 ViDoRe 干净文档图像 |
| degraded | 经参数化退化管线处理后的文档图像 |
| restored | 对退化图像执行前端复原后的文档图像 |

主要指标包括 `nDCG@5`、`MRR`、退化强度-性能曲线、复原增益曲线和 Patch 嵌入分布变化。

## 研究内容二：视觉语言模型鲁棒性增强

即便经过前端复原，图像仍可能残留退化痕迹，或因复原操作引入伪影。仅依靠图像预处理无法完全解决模型表示分布偏移问题，因此需要在表示学习与推理阶段增强鲁棒性。

本方向包括三个技术路径：

1. 退化不变对比学习：构造同一页面的 clean-degraded 正样本对，在训练阶段显式拉近两者的 Patch 嵌入距离。
2. 风格归一化或域对抗训练：在编码器中探索特征分布对齐，使中间层特征在不同退化条件下保持一致。
3. 退化感知 Patch 置信度加权：在 ColPali 延迟交互得分中加入 Patch 质量或退化置信度，动态降低严重退化 Patch 对最终检索得分的误导性贡献。
